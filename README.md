# 不動產及估價法規 (Real Estate & Valuation Laws Database)

> **專為不動產估價師高考應試與實務從業量身打造的全法規與技術公報離線知識庫系統**

## 🌟 系統核心特色

1. **法條繁體中文語音朗讀（TTS）**：
   - 支援單條條文朗讀、自動滾動連續朗讀（背法條神器）、0.8x~1.5x 語速調整與正在朗讀條文動態發光。
2. **全數收錄 54 部法規 ＋ 15 部公會技術公報**：
   - **高考命題大綱 100% 涵蓋**：民法物權、土地法、平均地權、土地稅法、不動產估價師法、國土計畫法、區域計畫法、都市計畫法、都市更新條例、土地徵收條例及其所有施行細則與技術規則。
   - **實務重要規則與標準**：都市更新權利變換實施辦法、危老重建條例、非都管制規則、建築技術規則設計施工編精要、地籍測量實施規則、土地登記規則、國有財產計價方式。
   - **中華民國不動產估價師公會全聯會公報（第 1 號 ~ 第 15 號全集）**：含土地開發分析法（3號）、營造施工費標準（4號最新版）、直接資本化法（5號）、都更權利變換估價要領（6號）、瑕疵不動產估價（8號）、租金評估（9號）、權利估價（10號）、折現現金流量分析法 DCF（15號）等。
2. **手機優先體驗（Mobile-First & PWA 離線支援）**：
   - 支援「**加入主畫面**」，以全螢幕原生 App 模式運作，無需下載與安裝任何軟體。
   - **Service Worker 離線快取**：考場、捷運地下室、勘估工地現場無網路亦可順暢查閱全文。
   - **條號快速滑軌（FAB 快捷鍵）**：長篇法規一鍵彈出條號九宮格，單手點擊立即滾動直達。
3. **估價實務專業功能**：
   - **一鍵複製報告書引用**：點擊條文旁「📋 複製引用」，自動格式化為例如：  
     *「依據《不動產估價技術規則》第43條規定：『...』」*
   - **法條交叉參照（Cross-Reference）彈窗**：文中提及關聯法規條號時直接點擊彈窗查閱，不跳離當前閱讀位置。
   - **智慧縮寫條號搜尋**：輸入 `技術規則 43`、`都更 67`、`土地法 97`、`公報 5` 即可毫秒級直達指定條文。
   - **自訂法條收藏夾**：隨手打星號，保存常翻法條。
   - **OLED 極致深色夜間模式**：柔和低眩光，保護雙眼。

## 📱 手機如何使用與安裝為 App？

### 方法一：透過電腦區網（Wi-Fi）直接連線手機
1. 確保手機與電腦連在**同一個 Wi-Fi 網路**。
2. 在電腦上雙擊執行 `啟動不動產及估價法規.bat`。
3. 視窗會顯示您的電腦 IPv4 位址（例如：`http://192.168.1.100:8080`）。
4. 在手機 Safari（iPhone）或 Chrome（Android）網址列輸入該網址打開。
5. **加入手機桌面變成獨立 App**：
   - **iPhone (iOS Safari)**：點擊底部「分享」圖示 ➔ 選擇「**加入主畫面**」➔ 點擊右上角「新增」。
   - **Android (Chrome)**：點擊右上角三個點選單 ➔ 選擇「**安裝應用程式**」或「**新增至主畫面**」。
6. 完成後，手機桌面會出現「**不動產及估價法規**」金黃天平 App 圖示，往後打開即為全螢幕離線 App！

### 方法二：部署至免費雲端空間（隨時隨地全網可用）
本專案為**純靜態架構**（靜態 HTML + CSS + JS + JSON），無須後端伺服器或資料庫：
- **GitHub Pages**：將本資料夾推送到 GitHub 倉庫，在 Settings ➔ Pages 開啟即可取得永久免費 `https://<帳號>.github.io/<專案名>` 網址。
- **Cloudflare Pages / Vercel**：將本資料夾直接拖拉上傳，30 秒內自動生成全域高速 CDN 網址。

## 🔄 未來法規修訂時如何一鍵更新？

若未來立法院或內政部有最新修法（例如國土計畫法細則調整或技術規則修正）：
只要在終端機執行：
```bash
python scripts/build_database.py
```
腳本會自動連線**全國法規資料庫最新官方 API**，抓取最新公布條文並自動重新打包 `data/laws_data.json` 與 `data/laws_index.json`，瞬間完成全資料庫同步更新！
